# Таблица изменений — важные ограничения

- Запрошенный в задании ГОСТ 2.503-2013 утратил силу в РФ; с 01.03.2024 действует ГОСТ Р 2.503-2023.
- Для проектной/рабочей документации также проверить раздел 7 ГОСТ Р 21.101-2026.
- `change_table_template.csv` — пустая таблица из пяти граф; `change_register.csv` — технический пример.
- Допустимые значения графы «Лист»: «Зам.», «Нов.», «Все», прочерк. «Аннулир.» туда не пишем.
- Точное место таблицы на листе и геометрия граф — **ГИПОТЕЗА/ПРОВЕРИТЬ**.
