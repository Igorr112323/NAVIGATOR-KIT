# Передача порядка листов в пакетную печать

1. Открыть `print_order.csv` / `print_order.json`.
2. На Windows-стенде открыть SHEETSET и проверить порядок вкладок layouts.
3. Сравнить `file + layout + sheet_no` с таблицей.
4. Только после этого запускать штатную публикацию/печать.

**Не редактировать `.dst` напрямую:** формат не подтверждён как открытый, а nanoCAD 26 связывает порядок с вкладками.
