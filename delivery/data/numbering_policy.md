# Политика нумерации

1. Построить граф «файл ↔ лист ↔ штамп ↔ ведомость ↔ печать».
2. Найти дубли в пределах марки; первый лист в порядке файлов оставить.
3. `minimal_new_no` меняет только дубликаты, но оставляет пропуски.
4. `full_shift_new_no` перенумеровывает весь комплект 1..N и рекомендуется для конкурсного демо.
5. Ни один вариант автоматически не применяется к исходным чертежам без подтверждения ГИПа.
