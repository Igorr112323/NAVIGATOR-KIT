# Синтетические входные данные

**Это не реальные DWG заказчика.** Для воспроизводимого ночного POC созданы 120 валидных ASCII/UTF‑8 DXF R2010: 3 марки × 40 листов. В каждой папке один файл = один лист. Штамп эмулируется block reference с атрибутами `ATTRIB`.

- `synthetic_sets/АР/` — профиль `SPDS_FORM3_CLASSIC`.
- `synthetic_sets/КР/` — профиль `SPDS_FORM3_ALT`.
- `synthetic_sets/ОВ/` — профили чередуются.
- `reference_docs/` — текстовые заглушки ссылочных/прилагаемых документов (не PDF).
- `expected_registry.csv` — эталонный реестр с двумя намеренными расхождениями.
- `stamp_patch_request.json` — тестовые изменения атрибутов для dry‑run/rollback.
- `change_events.json` — демонстрационные операции changes.

Все дефекты (дубли, пустые поля, неверные форматы) внесены намеренно для проверки контролёров.
